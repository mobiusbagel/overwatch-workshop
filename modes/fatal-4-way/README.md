# Fatal 4-Way

4-team deathmatch on Halloween maps. Mostly lobby-settings-driven — the Workshop
script is currently a single stub rule.

## Setup (from the script text)

- **Mode:** Deathmatch — "Fatal 4-Way", described as "4-team deathmatch"
- **Maps:** Château Guillard (Halloween), Hollywood (Halloween)
- **Perks:** On, 100% generation
- **Respawn:** Self-initiated respawn off
- **Lobby:** map rotation after a game, max 12 spectators, never return to lobby,
  no team swap after match
- **Disabled heroes:** Anran, D.Mon, Doctrine, Domina, Emre, Jetpack Cat, Mizuki,
  Shion, Sierra, Vendetta (newer roster heroes)
